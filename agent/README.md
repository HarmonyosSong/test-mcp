# Legacy Python Agent Reference

This directory contains the retired PydanticAI implementation, tests, and historical evaluation cases. It is kept for migration review and behavior reference only; it is no longer an installable Python project or a supported runtime/test entry point.

The product Agent, provider integration, evaluation runner, and case operations are maintained under `runtime/` and use Mastra. The independent Python MCP services remain under `mcp_server/` and are still installed by `make setup`.
