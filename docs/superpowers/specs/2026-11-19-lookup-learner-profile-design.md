# 查学员信息轻量闭环

## 目标

进线仅确认学员信息时，不走故障排查：查档案（可选）+ 近 7 天登录设备线索，用信息模板收尾。

## 行为

| 输入 | 行为 |
|------|------|
| 无学员编号且无 uid | 追问补充学员编号或 uid |
| 学员编号（如 184010299547） | `lookup_learner` → 用 uid 调 log-mcp 查近 7 天 |
| 仅 uid（如 5570040） | 不调档案；直接 log-mcp；日志里有学员字段则顺带写出 |
| 近 7 天无命中 | 「最近 7 天未登录」 |
| log-mcp 不可用 | 有编号则仍回档案；设备侧说明暂不可查 |

识别：标签优先；纯数字 ≥11 位为学员编号，更短为 uid。

## 实现（轻量）

1. Skill `lookup-learner-profile`：流程与禁令写在 Skill 正文。
2. 系统提示词：命中查档意图时 load 该 Skill；输出用 `判定：信息查询` + 信息模板，不用故障模板。
3. 校验器/知音楼：接受 `判定：信息查询`（`info_lookup`），否则 IM 会落兜底句。
4. 设备查询：直接用现有 log-mcp 工具，不指定引擎。

## 不做

新编排路由、按 uid 查 UCenter、改 log-mcp 边界、扩展手机号查档。
