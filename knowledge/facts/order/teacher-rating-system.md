# 教师口碑值

## 事实

「教师口碑值」是给教师打分的外显机制（业务意图是让老师"卷"起来），在 B 端与 C 端两侧外显。

**计分（彼芯口径，总分 100）**：

| 指标 | 权重 |
| --- | --- |
| 家长表扬率 | 25 |
| 学员进步率 | 25 |
| 小灶覆盖率 | 25 |
| 错题重练率 | 15 |
| 做题完成率 | 10 |

**各业务线口径不同**：1对1 的计算指标当时"还没定"；素养 / 培优 / 国际 / 大学生"暂无计划"。
因此**不同业务线的最低外显分数也不同**。

**外显开关（多粒度，且默认关闭）**：

- 粒度：**全局 / 业务线 / 分校 / 最低外显分数 / 教师个人**；
- 文档写明「上线时**全局关闭**」，打开时按业务归属 + 分校 + 控分逐步推进；
- **代码印证**：模型字段 `teacherReputationShowSwitch` **默认 `false`**。

**外显位置**：教师主页、选课过程的班级列表、教师详情、教师风采、搜索场景、**口碑值筛选轴**
（若所有教师均未外显口碑值，**筛选轴整体隐藏**）。

**最低外显分数按业务线不同**（文档举例）：**彼芯 = 60 分、1对1 = 70 分**。

**白名单是「不给谁看」**：粒度能下沉到**教师员工编号**——
个别教师虽然达到了外显分档，但某项指标异常、不希望被展示，
可以走**邮件流程（需校长同意）**申请不展示。

**展示形式有明确限制**（容易误以为是缺功能）：

| 项 | 是否展示 |
| --- | --- |
| **各项指标数据** | ❌ 只展示**比例条**，**不展示数值** |
| **计算公式** | ❌ 不展示 |
| **指标说明**（如"什么是家长表扬率"） | ❌ 不提供（由业务定义） |

**跨带教师怎么取值**：本期**简单处理——取最高分值业务线**下的家长表扬数据；
文档自己标注了「**未来扩展素养的时候会有问题**」。
以彼芯与 1对1 的**共性参数**为基准：**班级名称、提交时间、反馈内容（1~3 张图片）**；
总分相同时取总分最高值。

**1对1 的 3.0** 把口碑值扩到了 **8 人班的主讲与班主任（辅导）**，并加了一条交互：
**当岗位 = 辅导 且 业务线 = 1对1 时**，教师人头点击展示**教师系统姓名**，
且**可以跳转教师主页**（其他情况人头不可点）。

## 判据

用户问「老师的口碑值是多少 / 为什么看不到口碑值」时：

1. **先看开关**——默认**全局关闭**；即使打开，也是按**业务线 + 分校 + 最低外显分数**逐步放开的，
   看不到可能只是不在范围内；
2. **看业务线**——只有彼芯有明确的五项公式，其余业务线当时暂无计划；
3. 「筛选轴怎么没了」→ 所有教师都未外显口碑值时，**筛选轴整体隐藏**。

## 例外

- 口碑值是**展示分，不能作为诊断证据**；
- 分数外显时做**四舍五入取整**。
