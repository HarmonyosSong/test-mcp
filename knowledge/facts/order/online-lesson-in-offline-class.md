# 面授 / 托管班里的「在线课次」

## 事实

**班级的授课类型 ≠ 每个课次的上课形式**——**面授班、托管班里可能混着在线课次**。

客户端对此有**明确提示**：当班级的**授课类型 = 面授 / 托管**、但**存在在线课次**时，
**班级详情页**和**大纲页**的标题旁会出现一个**提示按钮**，点击后的弹窗文案是：

> **第 {课次序号} 次学习调整为【在线网课】形式**

也就是说，**是哪个课次变成了网课，界面上会写明序号**——不用靠猜。

**托管班的「课次转在线」与「选修讲」怎么展示**（2025-06 起，APP 侧做的兼容）：

| 位置 | **转在线课次** | **选修讲课次** |
| --- | --- | --- |
| **学习首页 / 已完结页** | 「已学习次数 · 共几讲次」**要把转在线课次算进去** | 同上，**也要算进去** |
| **日历页 / 未来课表页** | 按**在线课次样式**展示；**课态标签取转班后的授课类型（在线）**；<br>保留「上课中 / 已结束 / 时间冲突」状态；**课次名称取当前班级名** | 正常展示；**课态标签取当前班级的课态**；<br>**固定展示「选修讲」副标题** |
| **学习二级页** | 课次时间 / 名称取班课 / 灯塔招简；<br>**回放、进教室按在线班级的逻辑**展示与跳转；云学习任务正常显示 | 课次时间取班课系统；<br>**课次名称拼接成「选修讲」+ 课次名称**；回放与面授 / 在线的选修讲一致 |

**注意**：转在线课次的**课态标签取的是转班后的授课类型（在线）**，而选修讲的**课态标签取班级自己的课态**
——**两张卡片的标签来源不一样**。
另外「未来课表页是否屏蔽选修讲」在 2025-06 时**未做调整**（保持现有逻辑）。

## 判据

用户说「报的是面授班，怎么有几次课要在线上 / 这个班到底是线上还是线下」时：

1. **先看班级详情页的提示按钮**——它会指出**具体是第几次课**调整为在线网课形式；
2. **授课类型是班级级字段，课次可以有不同的上课形式**——这不是选课选错，也不是录错；
3. 要确认某一次课到底怎么上，**以大纲页 / 课表为准**，不要只看班级的授课类型。

## 例外

- 提示只在**面授 / 托管**的班级上出现（在线班本身不需要提示）；
- 需求覆盖**培优 APP 与营业厅小程序**两端；
- **鸿蒙端「在线网课」「在线课次」「课次形式」全部零命中**（见代码核对）——
  可能是**文案由服务端下发**，也可能是**鸿蒙未跟随**，以当前版本实测为准。
