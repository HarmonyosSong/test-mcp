# 选课的「附近 5km」筛选

## 事实

**选课页 - 班级列表页的筛选标签里会多出一个「附近 5km」**——但它不是所有情况都出现。

**显示的前置条件**（两个都要满足）：

1. 用户**开启了「位置信息」权限**；
2. **附近 5km 内**有**当前班级列表所包含的教学点**。

**任一不满足就不显示这个 tab**，走默认筛选（默认选中第一个行政区）。

**几个细节**：

| 项 | 规则 |
| --- | --- |
| **5km 这个距离** | **支持后端配置**，后续按埋点数据调整 |
| **位置** | **默认选中**；**但它在竖侧列表里的次序，原文两处说法不一致**——一处说在**首位**，另一处说排在「**最近报名**」tab **下方**（"首位"可能是指"默认选中/优先展示"而非列表位置）。**以实际界面为准** |
| **距离展示** | 只有教学点**已录入经纬度**才显示距离；**< 1km 显示「<1.0km」**；**≥ 1km 显示一位小数**（四舍五入，如 `1.5km`） |
| **排序** | 按距离**由近及远**，**只显示距离 ≤ 5km 的教学点** |
| **教学点名称** | 每行最多 **10 个字符**，超出用「…」 |
| **回显** | 在「附近」里选中的教学点，**在它所属的行政区下也要显示为选中** |

**两个端的定位授权时机不同**（这一点最容易误判）：

| 端 | 申请时机 |
| --- | --- |
| **营业厅小程序** | **进入小程序后就申请**——而且一旦同意或拒绝，**授权关系会记在后台，直到用户主动删除小程序** |
| **培优 APP** | **只在进入「我的 - 服务中心」时**才申请 |

所以「**APP 里怎么不弹定位授权**」是设计如此——**选课页它不主动要权限**，
没有权限时那个「附近 5km」tab 自然就不显示。

## 判据

1. **「怎么没有附近 5km」** → 查**定位权限**开没开，以及 **5km 内有没有这个列表里的教学点**；
2. **「距离显示得不准」** → 距离**只精确到 0.1km**，且 <1km 统一显示 `<1.0km`，不是数据错；
3. **「分享出去的班级，别人打开显示的距离不对」** → **分享不带分享者的经纬度**，
   用的是**打开者的定位**（设计如此）；
4. **「小程序删了重进还记着我的授权」** → 小程序的授权关系记在**微信后台**，**要删掉小程序才会清**。

## 例外

- 「附近 5km」只覆盖**选课页的班级列表筛选**，不是全局能力；
- 5km 是**可配置值**，以当前配置为准。
