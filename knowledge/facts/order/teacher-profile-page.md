# 教师主页

## 事实

教师主页是用户「初筛」老师的主要入口——近 3 个月累计访问 **316.7 万次**，最高单日 15.7 万。

**入口**：搜索-教师卡片、服务中心-教资 / 教师风采-教师卡片、班级详情页-教师卡片、
班级列表页-班级卡片-教师头像。

**两条容易踩的规则**：

1. **班级课次价格分两种身份**：
   - **是学员** → 展示**学员优惠价**；
   - **非学员** → 展示剩余课次的**原价**。
   所以「同一个班我看到的价和别人不一样」可能是身份差异，不是故障；
2. **评价不在主页展开**：超过展示行数用「...」表示，**主页不做展开收起**——
   要看全文得点《查看全部》进全部评价页。

**其他**：

- 班级列表按岗位分两套数据源：「主讲的班级列表」查"班级主讲 = 当前教师"，
  「真实辅导的班级列表」查"班级辅导 = 当前教师"；
- **虚拟教师**不进主页，走原班主任固定文案页面（命名见 `virtual-teacher-naming`）；
- **分享功能 v1.0 没做，v1.1 补上了**（2025-08）：新增**分享 btn**，点「微信」跳微信，
  分享标题取**教师系统姓名**、封面用**统一默认图**；
- **导航**：新增一个导航 icon（**整行都是热区**），点击调起导航组件——
  **iOS / 鸿蒙**用系统自带地图 ＋ 已安装的地图 APP，**Android**用高德 / 百度 / 腾讯，
  **都没装则调起应用商店**；同期把选课页的教学点导航也对齐（**iOS 原本能跳但没路标、
  Android 完全不能跳**，改成一致并加路标）；
- **教师风采为空时整个板块隐藏**，不再展示无意义的占位图。

## 判据

用户说「老师主页的价格不对 / 评价看不到」时：

1. **价格** → 先问是不是学员（学员价 vs 原价），再看剩余课次数；
2. **评价** → 主页只显示摘要（超出用「...」），全文在《查看全部》里；
3. **虚拟教师** → 不会进主页，会停在固定文案页。

## 例外

- 数据是 2025-07 的口径，入口与规则可能已微调；
- 客户端只渲染，教师信息与价格来自服务端。
