# 优惠券与优惠活动的规则

## 事实

**先分清两个概念**：**优惠券**（券）与**优惠活动**（限时购 / 联报折扣 / 联报立减 / 拼团）——**两者规则不同**。

### 一、能不能叠加（家长最常问的）

| 组合 | 能否叠加 |
| --- | --- |
| **优惠券 ＋ 优惠活动** | ✅ **可以叠加** |
| **普通优惠券 ＋ 普通优惠券** | ❌ **不能叠加** |
| **普通优惠券 ＋ 老带新 100 元券** | ✅ 可以，但**老带新只能叠 1 张非老带新券** |

> **注意**：申请流程里的「**是否叠加使用**」指的是**券与券之间**，**不是券与活动**——
> 这是最容易理解错的一处。

**活动之间的互斥**：

| 活动 | 能叠加 | **不能叠加** | 同班同有效期上限 |
| --- | --- | --- | --- |
| **限时购** | 大多数优惠券 | **联报立减、联报折扣、拼团** | **3 个** |
| **联报折扣** | 大多数优惠券 | **限时购、拼团、联报立减** | **3 个** |
| **联报立减** | 大多数优惠券 | **联报折扣、限时购、拼团** | **3 个** |
| **拼团** | 大多数优惠券 | **任何其他优惠活动** | **同班同时段只能有 1 个拼团** |

联报另有一条：**多班 / 多科可以同时设置**，但「**暑秋联报**」**和多班多科不能同时设置**，寒春同理。

### 二、优惠生效的前提（「为什么优惠没生效」）

- **班级必须先开班**——**未开班不可以设置优惠**；
- **班级（版本）名称必须和申请时一致**——**改了版本名，原优惠设置直接失效，需要重新申请**；
- **改完版本名要等 24 小时**，营销平台才会更新为新名称——**改完别马上申请，等一天**。

### 三、没填到班次时，优惠范围会有多大

要填的是：**授课类型 / 年份 / 产品类型 / 学季 / 年级 / 学科 / 版本名称 / 限额标签 / 班级原价**。
**只填到学科**（不写版本名称）→ **该学科下所有班级都适用**。

> ⚠️ **在线班一定要注明「限额标签」是大班还是小班**——**不注明就大班小班都享受优惠**。

### 四、有效期与作废

| 项 | 规则 |
| --- | --- |
| **优惠券有效期** | **具体到天**，建议不超过 **6 个月**；**无法修改** |
| **优惠活动时间** | **具体到分钟**，建议不超过 **3 个月**；开始后、截止前**可以改结束时间**（走 OA 审核） |
| **限时购活动时段** | 默认每天 `00:00:00-23:59:59`（无特殊需求不用改） |
| **停用优惠活动** | 审核通过且**已开始**的活动才可停用，停用要**走审批** |
| **停用优惠券** | 只有**线下发放**的券可停用；**未发放的券码自动作废，已发放且用户已绑定的仍可继续使用** |

## 判据

1. **「两个券怎么不能一起用」** → **普通券之间本来就不能叠加**（只有老带新能叠一张）；
2. **「优惠怎么没生效」** → 依次查：**班级开班了吗** → **版本名改过吗** → **是不是改完名不到 24 小时**；
   **如果是「某张券用不了」，那是另一套校验（四层原因），见 [[coupon-unavailable-reasons]]**；
3. **「小班怎么也有优惠 / 大班才有才对」** → 申请时**没注明限额标签**，导致大班小班都适用；
4. **「券能退吗」** → **优惠券有效期不能改**，活动结束时间可以改。

## 例外

- 优惠的**申请入口**已从「知音楼 OA 流程」迁到「**营销平台**」（1对1 优惠 2025-12-30 上线）；
- 本条目记的是**规则**，不是**申请流程**——流程细节看营销平台的操作手册；
- 优惠的**展示**（券在哪些页面露出）是另一回事，见 [[zero-price-purchase]] 里"0 元走领券"的部分。
