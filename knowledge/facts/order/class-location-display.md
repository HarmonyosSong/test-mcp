# 班级地点只展示到教学点

## 事实

**选课链路上，班级地点只外露到「地区-教学点」，不显示具体教室号。**

原因是业务侧发现：选课阶段就暴露具体教室，**存在被偷听课的情况**；产品侧评估后认为提前暴露教室
可能导致内部系统数据外泄，因此收窄到教学点。

- **适用**：课态 = 线下 / 彼芯 / 学习空间；授课类型 = 面授 / 托管 / 双师的**普通班**；
- **1对1 更严**：业务归属 = 学而思1对1 的卡片，地点**只显示「教学点」**——
  **连地区、服务中心、教室都不含**，其他业务归属维持原逻辑；
- **展示形式**：`地区-教学点`；
- **范围**：培优 APP 的班级列表页、班级详情页（营业厅小程序重构后同步）；
- **历史变更**（2024-06）：此前班级卡片展示的是「**区 + 服务中心**」（例如"南海区佛平三路服务中心"），
  **缺失教学点**——那是双减前"本地服务属性强、服务中心密集"时代的遗留（家长联系服务中心办事，
  但服务中心并非实际上课地点）。后来统一改成展示**实际学习的教学点**，
  作为交易筛选与查询上课地点的依据。

| 环节 | 文件 |
| --- | --- |
| 订单 / 购课单模型 | `XesOrder/src/main/ets/components/orderBusiness/Model/OrderModel.ets`、`CartPrepareOrder.ets` |

## 判据

用户问「为什么看不到教室号 / 上课在哪个教室」时：

1. **这是设计如此**——选课阶段**只到教学点**，不是信息缺失；
2. 具体教室通常在**开课前**通过其他方式告知，选课页面不会出现；
3. 若用户看到的地点与预期不符，先确认**教学点**有没有选对。

## 例外

- 只覆盖**普通班**，其他类型班级的地点展示另算；
- 具体教室信息在后台有，只是**不在选课链路上外露**。
