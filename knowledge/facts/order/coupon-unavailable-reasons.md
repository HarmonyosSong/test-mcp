# 优惠券为什么用不了

## 事实

**「账户里有券，但买这个商品用不了」**是 1对1 报课的高频问题——券的校验维度很多，
而且**订单预览默认只展示「可用券」**，**没有可用券时根本进不了选券窗口看原因**，
所以这类问题通常只能人工排查（先问学科，疑难再找产品/研发）。

**判断一张券能不能用，看三组对象**：

| 对象 | 要看的信息 |
| --- | --- |
| **学员** | 学员编号、**券归属**、**系统计算的新老生身份**（只在券配置要求时才查其他资格） |
| **优惠券** | 实例券 / 批次、状态、有效期、券型、**金额门槛**、**商品范围**、使用场景、引用规则 |
| **商品** | 商品 ID、业务分类、年份、学季、年级、学科、产品类型、授课类型，以及**本次购买金额、课次、缴费期次、加课 / 联报场景**；<br>还要看关联信息：分期商品的**历史用券记录**、**同一订单内的其他商品** |

**原因按四层校验，命中第一层不满足的就直接返回、不再往下看**：

| 层次 | 原因 | 文案 |
| --- | --- | --- |
| **1. 券状态与归属** | **未生效** | 该券尚未生效，将于`{生效时间}`生效。 |
| | **已过期** | 该券已于`{过期时间}`过期。 |
| | **已使用** | 该券已使用，不能在本次报名中重复使用。 |
| | **已作废** | 该券已作废。 |
| | **被其他订单占用** | 该券已被其他订单占用，本次暂不能使用。 |
| | **归属不符** | 该券不属于当前学员。 |
| **2. 学员资格** | **新生 / 老生身份不符** | 该券仅限`{适用身份}`使用，当前学员为`{学员身份}`。 |
| **3. 商品范围** | 商品类型 / 业务分类·产品线 / 年份 / 学季 / 年级 / 学科 / 产品类型 / 授课类型 不符；指定商品范围不符；其他已配置范围不符 | 「该券适用于`{X}`，当前商品`{Y}`」这类模板 |
| **4. 购买条件与优惠组合** | **金额未达门槛**，以及优惠组合类规则 | 该券需满`{门槛金额}`元使用，本次计入金额为`{计入金额}`元。 |

## 用券限制规则（2026-09 起）

有人能用**分期购买、拆分商品、拆分订单**重复使用大额券——**课次单价被压得过低、影响营收目标**
（顾问绩效按**订单单数**结算，也存在拆分动机）。所以加了「**用券限制规则**」：

- 把**多个券批次纳入同一条规则**，**同一学员在相同「年份 ＋ 学季 ＋ 年级 ＋ 学科（＋产品类型 ＋ 授课类型）」下，
  规则关联的券批次合计只能使用一张**；
- **跨商品、跨订单、分期的一期 / 二期都累计计算**；
- 规则**停用后，已引用的券不受影响**（避免停一条规则让所有券一起失去限制）；
- **续报期自动下单不使用任何已关联限制规则的优惠券**；
- **只对规则刷入之后新提交的订单生效，不回溯历史订单**。

## 判据

1. **「为什么这张券用不了」** → 按**四层从 1 往下捋**：先看**状态与归属**（最常见），
   再看**学员新老生身份**，再看**商品范围**，最后才是**金额门槛**；
2. **「明明有券，选券时却不显示」** → **订单预览只展示可用券**，不可用券默认不出现——
   **不是券丢了**；
3. **「同一张券想在第二个订单再用」** → 受**用券限制规则**约束，同规则下的券**合计只能用一张**；
4. **「券被占用了」** → 该券可能**被另一个未完成订单占用**，把那个订单处理掉即可释放。

## 例外

- 「券不可用原因」的展示**本期只做 1对1**，班课后续扩展；
  **C 端展示也不在本期**——先做**盘古 / 小驴的学员档案**；
- 「用券限制规则」在 2026-09 时标注「**开发不上线，10 月整体上线**」，以当前版本为准；
- 营销侧同期新增了业务归属「**人工智能**」。
