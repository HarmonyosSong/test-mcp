# 组合加购（班课渗透）

## 事实

**「组合加购」是"班课渗透"的手段**——把「**班课在读学员**」转化成「**1对1 在读学员**」。
背景是**高中班课与 1对1 的业务负责人已合并**，于是借「**合并下单**」降低班课学员买 1对1 的门槛。

**三种优惠形式**（第三种当时没做）：

| 形式 | 内容 |
| --- | --- |
| **1** | 买**特定范围的长期班班课**，**赠 0 元或 1 元的活动类 / 诊断类购买资格** |
| **2** | 买**特定范围的长期班班课**，**短期班打折** |
| **3** ❌ | 班课老生 0 元买短期班——**暂不支持**（靠自行导班实现） |

**几条硬约束**：

- **赠送 / 折扣的商品仅限 短期班、活动类、诊断类**；
- **加购的商品必须与班课「非同科」**——因为**班课辅导与 1对1 班主任还没合并**，同科会冲突；
- **加购价是「单课次固定价」，不展示原价**；
- **加购品在订单详情里不可叠加券**（这条是已定的），
  但**本期支持叠加「家委会」「员工子女」折扣**。
  ⚠️ **选券入口的具体处理（是否置灰、是否加提示语）评审时还挂着待确认**——
  上线口径以最终实现为准，别按"一定不可点击"回复用户。

**与其他优惠的关系**：

| 对象 | 关系 |
| --- | --- |
| **1对1 优惠（多科 / 暑秋 / 寒春）** | **互斥**（创建时就校验） |
| **优惠活动（限时购 / 联报立减 / 联报折扣）** | **同组取最优**；**优惠类型互斥**（创建时校验） |
| **同商品有多个加购价** | **取最优** |
| **同一商品条件出现在多个组合加购活动里** | ✅ **允许** |

**退费**：**班课与加购商品独立退费**。

**合规要求**（这块写得很细，值得照抄）：

- **避免「0 元免费学」这类措辞**——建议「报名正课可领取一节专属一对一体验课」，**不夸大、不诱导**；
- **避免展示「原价」**（防划线价虚假）——文案上用「**门市价**」，且**无需原价成交记录**；
- **明码公示**：赠课的使用期限、**不可折现**、**退费时赠课不计入退款基数**、**过期作废**等都要写明；
- 所有赠课、折扣内容**写入官方示范培训合同**。

## 判据

1. **「怎么多了个加购价」** → 这是**组合加购**（买班课时带的），价格是**单课次固定价**；
2. **「加购的东西怎么不能用券」** → **设计如此**（但家委会 / 员工子女折扣可以叠）；
3. **「为什么加购的必须是别的学科」** → 避免与班课**同科冲突**（班课辅导与 1对1 班主任尚未合并）；
4. **「退课时赠的课怎么算」** → **赠课不计入退款基数**，且**班课与加购商品是独立退费**。

## 例外

- 优惠**按分校逐批开启**（对比已开启与未开启分校的渗透率）；
- 预期 **2026-09 起在秋季使用**（暑期 1对1 产品较少）；
- **加购品的选券入口、预课表课次不一致**等细节，**评审时还挂着待确认**。
