# 鸿蒙一期的学习任务屏蔽

## 事实

**鸿蒙端的学习二级页做过一次「刻意的减法」**：鸿蒙一期为控制开发工作量，
**除「在线学习」的去学习 / 进教室入口外，其余学习任务本期一律屏蔽**，
后续版本再逐步放开。

**保留的入口**：

| 入口 | 状态 |
| --- | --- |
| **在线学习**（去学习 / 进教室） | ✅ **唯一保留的学习任务入口** |
| **资料** | ✅ 保留 |
| **报告** | ✅ 保留 |
| **评价** | ✅ 保留 |
| **其余学习任务**（作业、打卡等） | ❌ **本期屏蔽** |

需求覆盖 **学而思 APP ＆ 学而思 HD 的鸿蒙端**（iOS / Android 不受这条影响）。

## 判据

用户 / 测试说「**鸿蒙上学习页少了东西 / 别的手机有、鸿蒙没有**」时：

1. **先对照上表**——资料、报告、评价、在线学习是保留的，**其余的缺席是本期屏蔽**；
2. 这**不是 bug，也不是鸿蒙适配漏做**，是**一期主动砍的范围**；
3. 要判断某个入口该不该有，**先看它是不是"学习任务"**——是的话，一期就可能是故意没有的。

## 例外

- 这是 **2024-12 的一期口径**，文档明确说「**后续版本再逐步放开**」——
  所以"鸿蒙没有"这个结论**有时效**，**以当前版本为准**；
- **iOS / Android 上这些入口是有的**——做对比测试时**别把它们当基线**。

## 来源

- 《鸿蒙APP一期-学习任务屏蔽处理》知音楼 `https://s.tal.com/a/JBpuv7`（2024-11-26，刘东）——
  屏蔽范围与保留清单的来源（文档正文很短，只有一段背景 ＋ 一段需求说明）
- **人工核实入口，agent 无访问能力**。

**客户端代码核对结果**（仓库 `xesapp`，分支 `releaseV/20260921`，2026-09-23）：
「去学习」命中 `XesStudy` 的 `NewCalendarViewModel.ets`、`XesTimetableResponseModel.ets`、
`StudyPageModelV2.ets`；「学习任务」命中 `XesWebView` 的 `GrowUpClickUtils.ets`
（**注意：鸿蒙仓库里这些入口是存在的**——说明**后续版本确实放开了**，
本条目的"屏蔽"口径**需按当前版本复核**）。
