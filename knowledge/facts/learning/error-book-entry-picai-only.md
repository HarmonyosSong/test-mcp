# 错题本入口（仅彼芯用户可见）

## 事实

「错题本」入口位于**我的 → 学习服务**，**仅面向报名过彼芯课程的用户开放展示**。
分校、年级都不限制——**唯一的门槛是有没有报过彼芯**。

- **内容范围**：课中错题、校内错题；
- **录入文件类型**：仅图片（C 端 ≤4M ×8 张；B 端 jpg），PDF 仅用于导出——
  见 [[error-book-upload-file-types]]；
- **版本**：iOS 无限制；Android 最低 **V7.81.0 / V5.81.0**；
- 详情页由**小驴团队**提供（H5），鸿蒙侧只做容器与桥接。

代码位置（鸿蒙侧）：

| 环节 | 文件 |
| --- | --- |
| 我的页（学习服务入口） | `XesMine/src/main/ets/components/mainpage/MineTabPage.ets`（`id = 3` 为学习服务） |
| 错题本分享页 | `XesClassLearn/src/main/ets/page/ClassLearnErrorBookSharePage.ets` |
| 分享 PDF / 相机的 H5 桥接 | `XesWebView/src/main/ets/components/XesWebview.ets` |

## 判据

用户说「找不到错题本 / 错题本用不了」时：

1. **先确认是否报名过彼芯课程**——没报过就是**不展示**，不是功能缺失；
2. 报过但仍看不到 → 检查 Android 版本是否低于 V7.81.0 / V5.81.0；
3. 入口在**我的 → 学习服务**，不在首页或学习页。

## 例外

- 彼芯业务在**逐步放开**，早期只有部分用户可见——"别人有我没有"可能是放开批次不同；
- **入口位置存疑（重要）**：2025-07 的品牌改版需求（《学而思APP品牌焕新：消息中心样式改版》）
  在「学习服务调整」一节写着「从新版 APP 起，隐藏【日历】【我的书房】【错题本】功能」。
  本条记的「我的 → 学习服务」出自 2024-12 的开放需求，**当前线上实际入口需人工核实**——
  两篇文档对同一入口的说法不一致，不要只信一篇；
- 错题本详情页是 H5，客户端搜不到它的业务逻辑，只能找到入口和桥接。
