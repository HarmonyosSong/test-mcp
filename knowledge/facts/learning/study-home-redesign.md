# 学习首页改版与课次卡片按钮

## 事实

**学习首页做过一次大改版**（首页与日历页融合、保留未来课表页；已完结页改为展示全部已结课与未结课班级）。
**版本门槛：APP ≥ `V7.95.0`、HD ≥ `V5.95.0`**，覆盖 **iOS / Android / 鸿蒙**。

### 课次卡片的 8 个按钮

这是改版后最容易出问题的地方——**每个按钮都有自己的展示时机**：

| 按钮 | 展示规则 | 点击去哪 |
| --- | --- | --- |
| **添加老师** | 本节课**配了老师微信** 且 学生**未添加** 且 **课前**时段 | 老师微信二维码页 |
| **看资料** | 本节课**有资料** 且 **课程未开始** | 资料列表页 |
| **进教室** | 本节课是**在线课 / 双师家庭班** 且 **上课中** | 在线课堂页 |
| **看回放** | **回放已生成**（同学习二级页回放按钮高亮规则） | 回放视频页 |
| **家长旁听** | **1对1**：课程类型 = 1人班，**上课时段内展示、超出下课时间隐藏**；<br>**非 1对1**：按学习二级页规则。<br>⚠️ **这条窗口只适用于「学习首页的课次卡片」**——**学习二级页上的家长旁听是「常驻展示、无隐藏规则」**，<br>两处口径不同，见 [[class-replay-and-cloud-listening]] | 家长旁听页 |
| **云听课** | **新版**：面授 且 课中交互模式 = 大小屏，且**上课时段内**展示、超下课隐藏；<br>**旧版**：面授课且在上课时段内。<br>⚠️ **这是「学习首页课次卡片」的窗口**——**学习二级页上云听课是「课前 30 分钟起、展示后无隐藏」**，<br>两处口径不同，见 [[class-replay-and-cloud-listening]] | 对应版本的详情页 |
| **看报告** | **有报告生成**（同学习二级页报告按钮高亮规则） | 报告详情页 |
| **写评价** | **下课后**展示，**评价完成即隐藏** | 评价页 |

**按钮的排序是固定的**：`01 看资料 → 02 进教室 → 03 看回放 → 04 家长旁听 → 05 云听课 → 06 看报告 → 07 写评价`
（按序号排，缺哪个就跳过哪个）。

⚠️ **第 8 个按钮「添加老师」不在这套序号里**——需求原文的排序只列了上面七项，
**它的位置以实际界面为准**（别按这份序号去推它的位置）。

### 卡片上的其他信息

| 项 | 规则 |
| --- | --- |
| **上课标签** | 按时间三段：**未开始** / **上课中** / **已下课** |
| **课次名称** | **优先取灯塔的大纲信息**，没有才取班课系统；格式「**第N次·课次名称**」 |
| **地址信息** | **仅在面授 / 线下 / 托管课态下展示**；<br>**只有学而思 APP 与学家云 APP（iOS & Android）支持教学点导航** |
| **共有 N 节课** | 取**当前日期下所有关联学员账号**的课程总数；<br>**如果有阅后即焚的自建课，卡片隐藏时数量要 -1** |

### 自建课卡片

上课时间取**订单系统**的课程开始时间，格式 `hh:mm`（**忽略结束时间**）；
**晚于 21:00 显示「时间待定」**；课程名取创建时填写的名称。

## 判据

用户说「**学习页某个按钮不见了 / 该出现的时候没出现**」时：

1. **对着上表查时机**——按钮是按**时间窗口**出现的（课前 / 上课中 / 下课后），
   不在窗口内**本来就不展示**，不是丢了；
2. **「看回放」要回放已生成**、「看报告」要报告已生成——**没生成就不显示**；
3. **「写评价」评价完就消失**——是设计；
4. **HD 与手机端不一样**：**「当日课程 / 当日任务」按钮仅 APP 有、HD 隐藏**；
   教学点**导航功能只有 iOS & Android 的学而思 / 学家云 APP** 有。

## 例外

- 改版是**分两期**的：一期（首页 + 已完结页）、二期（学习任务上提至首页、资料页改造）——
  **现在处于哪一期以当前版本为准**；
- 版本门槛是 `V7.95.0`，**低版本看不到新版首页**；
- **1对1 APP** 的导航栏（学员头像、昵称、切换学员、退出）**保持现状**，不跟这次改版。
