# 课堂笔记进资料页

## 事实

托管面授课的**课堂笔记（PDF）**会在课后推送到学生端，在**资料页**查看和下载。

- **背景**：此前由老师手动发微信群，查历史体验差、容易遗漏；
- **覆盖课程**：**托管面授**班级（对照高中在线班已有的能力）；
- **入口路径**（三条）：
  1. 新版学习首页 → 讲次卡片「资料」按钮 → 资料页；
  2. 新版学习首页 → 学习二级页 → 讲次资料入口 → 资料页；
  3. 老版学习首页 → 学习二级页 → 讲次资料入口 → 资料页。

代码位置（鸿蒙侧）：

| 环节 | 文件 |
| --- | --- |
| 资料页 | `XesStudy/src/main/ets/components/datalib/StudyDataPage.ets`（`title: '课堂笔记'`） |
| 课堂收获类型枚举 | `XesCourseCenter/src/main/ets/components/viewmodel/ClassLearnDetailBean.ets`（含「6：课堂笔记」、8：课堂资料） |

## 判据

用户说「课堂笔记在哪 / 老师发的笔记找不到」时：

1. 指引到**资料页**（三条入口见上），笔记是 **PDF 文件**；
2. 用户说「以前是微信群里发的」→ 现在改走 APP 资料页，群消息不再是唯一来源；
3. 覆盖范围只有**托管面授**班级，其他课型没有这个推送。

## 例外

- 「课堂笔记」在课堂收获类型枚举里是**独立类型**（值 6）；「课堂资料」（值 8）是 2020-12-23 版本
  用来替换「讲义资料 + 课堂笔记」的**总入口**——两者概念不同，别混为一谈。
