# 自学课的展示规则

## 事实

**自学课有两种开课方式**（2025-03 口径）：

| 类型 | 状态 |
| --- | --- |
| ~~前置排课~~ | ❌ **已不支持开通** |
| **后置排课 - 一次性全解锁** | ✅ 缴费报班后**所有课次一次性解锁** |
| **后置排课 - 设置解锁时间** | ✅ 开班建课时设定**每个讲次的解锁时间**（**长期方案建议选这个**） |

**它在各页面的表现**：

| 页面 | 规则 |
| --- | --- |
| **学习首页** | **一次性全解锁**：缴费后展示，**展示 10 天后归入「已完结课程页」**；<br>**设置解锁时间**：缴费后 ~ **最后一讲次解锁 + 10 天**内展示，超时归入已完结页 |
| **已完结课程页** | 展示已结课且**满 +10 天**的课程；**按结课时间倒序**——最近完结的在最上面（取法见下） |
| **日历页** | **所有自学课都不展示** |

**「结课时间」怎么取，自学课不一样**（排序全靠它）：

| 课程类型 | 结课时间取 |
| --- | --- |
| **非自学课、自学课 - 前置排课** | 班级**最后一讲次的下课时间** |
| **自学课 - 后置排课 - 指定解锁时间** | 当前班级**最后一次讲次的下课时间** |
| **自学课 - 后置排课 - 一次性全解锁** | 当前班级最后一讲次的**解锁时间**（**不是下课时间**） |

**排序规则改过一次**：旧规则是**按类型分层**——
「非自学课 ＞ 自学课-前置排课 ＞ 后置排课-指定解锁时间 ＞ 后置排课-一次全解锁」；
2025-03 才改成**统一按结课时间倒序**。所以老用户会觉得「**顺序跟以前不一样了**」。

**「+10 天进已完结」这条面向所有课程**：所在班级**结课日期 + 10 天**后进入已完结列表，
不满足条件的**继续在学习首页展示**。

**为什么会有自学课**：分校用自学课挂**互动视频**，给长期班做「**互动预习视频**」的内容补充——
引导用户在正价课**每节课开课前**看对应讲次的互动视频，完成预习。

## 判据

1. **「自学课怎么跑到已完结里去了」** → **+10 天后归入**，是设计，不是分类错了；
2. **「日历页怎么找不到自学课」** → **所有自学课都不在日历页展示**；
3. **「已完结页的排序怎么这么乱」** → 按**结课时间倒序**；要快速定位可以用**筛选**（学科、类型 = 活动类）；
4. **「想让自学课在首页留久一点」** → 让分校改用「**后置排课 - 设置解锁时间**」，把解锁周期拉长。

## 例外

- **「前置排课」已不支持开通**，但**老数据仍可能存在**，遇到时不要当成新问题；
- 这是 2025-03 的口径，**+10 天**这个阈值以当前版本为准；
- 自学课在卡片上的**样式**是另一回事（见 [[study-page-style-matching]]）。
