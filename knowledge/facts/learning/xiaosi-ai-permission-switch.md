# 小思AI / 蛋君 的功能开关

## 事实

小思AI 已更名**蛋君**（集团统一改名）。它是首页的一个 tab——**非登录态也只展示「首页 / 蛋君 / 我的」三个 tab**。
家长可以在权限设置里关掉它。

**开关名字随版本变**（两个名字会长期并存，排查时别只认一个）：

| 应用版本 | 权限设置页里显示 |
| --- | --- |
| ≥ **V7.104.0** | 「蛋君功能开关」 |
| V7.102.0 ~ V7.103.x | 「小思AI功能开关」 |
| < V7.102.0 | **没有这个开关** |

- **位置**：我的 → 设置 → 权限设置；
- **默认**：开启；状态存**服务端**；
- **生效范围（最容易误判的地方）**：
  - **账号**：一次操作对「当前登录账号 + 用户中心已关联的全部账号（**1+5 模式**）」全部生效；
    之后新绑定的账号**遵循该账号当前的配置**，不追溯；
  - **应用**：学而思 APP / HD、学家云 APP / HD **四个端一起生效**；
- **审核态**：开关受 APP 审核开关影响，审核状态下**隐藏**；
- **生效方式因端而异**：
  - APP：**实时**显隐，成功后 toast「小思AI功能已关闭 / 已开启」，失败提示「设置异常，请稍后再试」；
  - HD：提示「功能配置已更新，**在重启应用后生效**」——**不重启不生效**。

代码位置（鸿蒙侧，小思AI 主体是 H5，原生只做容器与桥接）：

| 环节 | 文件 |
| --- | --- |
| 蛋君 tab（首页） | `products/xes/src/main/ets/pages/home/HomePage.ets`（`title: "蛋君"`） |
| 小思 AI 悬浮窗桥接 | `XesWebView/src/main/ets/components/RegisterHandlerUtil.ets` |
| 原生与 H5 通信 | `XesWebView/src/main/ets/components/NativeCallH5Util.ets` |

## 判据

用户说「关了小思AI / 蛋君，孩子还能用」时：

1. **先问哪个端**：HD 上关完**必须重启应用**才生效（APP 是实时的）——这是最常见的"关不掉"；
2. **再确认账号**：1+5 模式意味着家长账号的操作会让关联的孩子账号一起生效；
   反过来，如果孩子在**未被关联**的账号上用，那不受影响；
3. 用户说「APP 上找不到小思AI」→ 它可能已**改名成「蛋君」**；
4. 用户说「权限设置里没有这个开关」→ 检查版本是否 < V7.102.0，或处于审核态。

## 例外

- 低于 V7.102.0 时**页面无开关**，但小思功能是否展示仍受**服务端开关数据**控制——
  开关不出现 ≠ 功能没被关；
- 早期方案里的「配置文件黑名单」已被替代：技术支持老师可通过**模拟登录替用户操作**开关。
