# 托管类班级在 APP 学习页的表现

## 事实

**这一条不只属于彼芯**：**彼芯班和素养托管班在 APP 里的表现是同一套**，
连 toast 文案都**一字不差**——「请前往教学点，当前应用不支持上课，详情请咨询教练」。
所以看到这句提示，**先想到"这是个托管类班级"，不要只往彼芯上找**。

**它们在 APP 里是「能看到、但不能在 APP 上课」的**（2024-12 口径）：

| 项 | 表现 |
| --- | --- |
| **页面样式** | 课态 = **彼芯** → 走**自学课**页面样式，**封面图蓝色**；课态 = 在线 → 常规班级样式 |
| **去自习 btn** | 课态 = **彼芯** → 点击弹 Toast「**请前往教学点，当前应用不支持上课，详情请咨询教练**」（学而思 APP & HD、学家云 APP & HD 都如此）；<br>课态 = **在线** → 正常跳课堂 |
| **服务 btn** | **仅手机端**（学而思 APP、学家云 APP）显示，点击跳**彼芯小程序 - 服务页**（不指定班级 / 课次）；**学而思 HD 不展示** |
| **报告 btn** | **屏蔽** |
| **资料 btn** | 有资料任务时高亮，可跳详情页 |
| **教学点** | 地址前拼接「**（请前往教学点）**」，例：`(请前往教学点)海淀区-测试教学点10120`——**授课类型 = 托管 & 双师都展示地址** |
| **教师** | **只取辅导**（**2024-12 口径**；**2025-06 岗位对调后托管改取主讲的头像与姓名**，岗位名仍是「教练」——见 [[virtual-teacher-naming]]）；虚拟老师显示「**彼芯教练**」 |

**「进课堂 / 看回放」按钮的处理分新旧版本**（托管口径）——这是最容易误判的地方：

| 版本 | 行为 |
| --- | --- |
| **新版本** | 按钮**照常展示**（复用"在线课"的展示逻辑），但**点击禁止跳转**，弹上面那句 toast |
| **老版本** | **由服务端直接隐藏**进教室 btn 和看回放 btn |

所以「**老版本上按钮全不见了 / 新版本上点了没反应**」——**两种都是设计**，
不是哪个版本出了 bug。

**托管类班级在学习页的其他固定表现**：课态显示「**学习空间**」（彼芯则显示「彼芯」）；
**无任务、也没有「去上课」按钮**；教学点前拼接「（请前往教学点）」；
教师**只取辅导**（**2024-12 口径**，2025-06 岗位对调后托管改取主讲，见 [[virtual-teacher-naming]]）、
岗位名「教练」、**禁止点击**（进不了教师主页）。

**版本限制**（⚠️ **只针对「学习计划」与「已完结页」这两个页面**）：
**学家云 / 学家云 HD** 才展示这批彼芯课程（需求原文写「课态 = 彼芯」，
**按班课字段应理解为业务归属 = 彼芯**），其他应用端本期不展示。
**学习二级页不受这条限制**——学而思 APP & HD 也展示彼芯课，所以上面那个 toast 在学而思端同样会出现。

## 判据

用户说「点了没反应 / 怎么上不了课」时：

1. **「点了去自习弹出一句话让我去教学点」** → **对上了**，彼芯的课在 APP 里**本来就不支持上课**，
   要去教学点，或走**彼芯小程序的服务页**；
2. **「平板上怎么没有服务按钮」** → 服务 btn **只在手机端**展示，**HD 不展示**，不是漏做；
3. **「彼芯的课怎么没有报告」** → **报告 btn 被刻意屏蔽**；
4. **「教学点前面那串『请前往教学点』是什么」** → 固定拼接文案，不是脏数据。

## 例外

- 这是 **2024-12** 的口径；彼芯的上课模式后续改过多轮
  （托管 AI、书机结合 / 智能伴学等，见 [[class-replay-and-cloud-listening]]），**以当前版本为准**；
- ⚠️ **「课态 = 彼芯」是学习侧的叫法，别当成班课字段值**：在班课字段里，
  **「彼芯」是业务归属（值 = `9`）**，彼芯托管班的**课态值其实是「托管」**；
  「**学习空间**」才是课态的真实取值（`19`）。两套用词容易撞，完整矩阵见 [[coursestate-mapping]]。
  本文沿用了原始需求文档的写法（它用"课态=彼芯"指代这批班），**判断条件写「业务归属 = 彼芯」更准确**。
