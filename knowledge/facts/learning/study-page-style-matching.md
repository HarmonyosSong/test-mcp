# 学习页的样式（经典款 / 彼芯款 / 自学课）

## 事实

学习页和日历**不是一套样式**——课程走哪种样式，由「**类型 ＋ 业务归属 ＋ 授课类型**」决定；
客户端用 **`jumpMode` / `viewMode` / `curriculumViewMode`** 三个字段区分。

**客户端的取值**（`ClassBean` 里的注释原文）：

| 字段 | 取值 | 用途 |
| --- | --- | --- |
| **`jumpMode`** | `1` 经典款（**橙色**）、`2` 彼芯款（**蓝 / 紫色**，自学课用）、`3` 彼芯商品（蓝 / 紫色） | 学习页 / 日历（**跳转类型**） |
| **`viewMode`** | `1` 普通、`2` 自学（自学课用）、`3` 彼芯商品 | 学习页（**页面类型**） |
| **`curriculumViewMode`** | `1` 普通 / 自学课、`2` 自建（自建课用）、`3` 彼芯商品 | 日历（**页面类型**） |

**业务侧的匹配规则**（2025-01 起）：

| 类型 | 业务归属 | 授课类型 | 样式 |
| --- | --- | --- | --- |
| **班级** | **彼芯** | **双师 / 托管 / 面授 / 在线** | **经典款** |
| **商品** | — | — | **自学课样式** |

**这次调整的动机很实际**：彼芯要启用**云学习任务**做课后练习，
但**彼芯原来的学习二级页样式不具备展示任务的能力**——所以把彼芯班级**改回经典款**。

**大背景**：双减评估后各业务**逐步回归培优系统**（学而思 APP & HD、营业厅），
并**逐步停服此前因合规 / 风险管控 copy 出来的应用**。

**彼芯的术语演进链**（文档原话）：**学家 → 学习空间 → 彼芯托管 → 彼芯**。

**卡片信息里的三条**：

- **教学点**：**仅授课类型 = 双师 / 托管 / 面授**才展示，文案是「（请前往教学点）」＋ 地址；
- **老师**：**在线 / 面授 / 托管（2025-06 岗位对调起）→ 取主讲**；**双师（彼芯）→ 取辅导**；
  **不支持点击**；虚拟老师显示「彼芯教练」、岗位「教练」
  （**完整口径与时间线见 [[virtual-teacher-naming]]**——本条原始口径来自 2025-02，
  **托管那一格已被 2025-06 的岗位对调覆盖**）；
- **回放 & 任务标签**：**统一屏蔽**——未完成任务数、未看完回放数这两个标签都不展示。

## 判据

1. **「这个班的卡片怎么是蓝色 / 紫色的」** → 走的是**彼芯款**（自学课 / 彼芯商品样式），
   经典款是**橙色**的；
2. **「怎么没有任务 / 任务标签不见了」** → 先确认是不是**彼芯款样式**——
   那个样式**不具备展示任务的能力**（这正是它要改回经典款的原因），
   另外**未完成任务数、未看完回放数这两个标签是统一屏蔽的**；
3. **「教学点怎么不显示」** → 只有**双师 / 托管 / 面授**才展示地址，在线课不显示；
4. **「老师显示的是谁」** → **在线 / 面授 / 托管（2025-06 岗位对调起）取主讲**，**双师（彼芯）取辅导**；

## 例外

- 三个字段的取值来自**客户端注释**，**以服务端枚举为准**；
- 「彼芯款」是**过渡期样式**，业务正在往经典款收敛——**以当前版本为准**；
- 需求范围含**鸿蒙**（学而思 APP / HD、学家云 APP / HD 的 iOS & Android **含鸿蒙系统**），
  且**版本要求无限制**。
