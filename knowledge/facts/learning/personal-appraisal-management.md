# 个人评价管理

## 事实

**「我的 - 学习服务」里有一个「个人评价」入口**（2026-09 新增，培优 APP 与营业厅小程序），
用户可以查看**自己提交过的全部评价**，并对满足规则的做删除 / 重新评价。

**个人评价页**：

| 项 | 规则 |
| --- | --- |
| **排序** | 按**评价时间倒序** |
| **范围** | **只展示本人评价** |
| **页面标题** | 「个人评价」，并展示「**共 N 条评价**」 |
| **卡片标题** | `教师姓名 | 班级名称`，**最多 2 行**，超出省略号 |
| **卡片副标题** | `第N讲 · 课次名称`，**最多 1 行** |
| **其他字段** | 星级、评价标签、评价时间、评价内容、删除按钮 |
| **长内容** | 文字默认最多 **2 行**，超出时第二行末尾显示「**… 展开**」，点击展开 / 收起 |

**删除规则**：

- **只有 `can_delete = true` 的评价才展示删除按钮**——不满足规则的**根本不暴露删除入口**；
- 点删除 → **二次确认弹窗**，给出两个选择：
  1. **仅删除** → 删除并从列表中移除；
  2. **删除并重新评价** → 先删除，成功后**跳转到对应课次的评价页**。

**异常提示**（文案是固定的）：

| 情况 | 提示 |
| --- | --- |
| 删除失败 | 「删除失败，请稍后重试」（评价保持不变） |
| 删除成功但重评页打不开 | 「跳转失败，请稍后重试」（**评价已删除**，需从原课次评价入口重进） |
| 未登录点击入口 | 走登录流程，登录成功后进入个人评价页 |
| 接口失败 | 展示异常态「加载失败，请稍后重试」，可点「重新加载」 |
| 没有评价 | 展示空状态「暂无评价」 |

## 判据

用户说「我的评价在哪 / 想删掉评价」时：

1. **入口**：我的 → **学习服务** → **个人评价**（不在评价页里，在学习服务宫格）；
2. **「为什么没有删除按钮」** → 该评价**不满足删除规则**（服务端下发 `can_delete`），
   **不是没做**；
3. **「点了删除并重新评价，评价没了但没跳到评价页」** → 删除**已经成功**了，
   只是跳转失败，需要**从原课次评价入口重新进**；
4. **游客**点入口会先走登录。

## 例外

- 删除规则由**服务端**判定（`can_delete`），客户端只负责**要不要显示按钮**；
- 需求范围是**培优 APP 与营业厅小程序**，鸿蒙侧是否有该入口**需实测**；
- 评价**提交**时的敏感词拦截是另一套（见 [[appraise-sensitive-word-block]]）。
