# 学习报告为什么看不到（按分校白名单）

## 事实

**高中班课（高中学科）的学习报告在 APP 里本来是屏蔽的**——因为**部分分校的合规要求**。
2025-11 起改成**按「开班分校」配置白名单**，由业务决定哪些分校放开。

**放开的条件**（三列都要命中）：

| 维度 | 取值 |
| --- | --- |
| **学科** | 数学、语文、英语、物理、化学、生物、综合、政治、历史、地理 |
| **年级** | 高一、高二、高三 |
| **授课类型** | 面授、在线、托管 |

**本期开放的分校共 18 所**：
天津、上海、深圳、广州、济南、成都、南京、沈阳、杭州、佛山、西安、重庆、武汉、青岛、东莞、苏州、无锡、长沙。

**显示位置**：

1. **我的 - 报告列表页**：白名单内的课程展示班级信息与已生成的报告（可点进详情）；
   **名单外的什么都不显示**；
2. **学习 - 学习二级页**：白名单内的课程在**课次卡片**上展示报告入口
   ——**报告已生成则按钮高亮，未生成则置灰**；
3. **新版学习页**的课次卡片报告入口**同样受这个白名单控制**。

## 判据

家长 / 顾问说「APP 里看不到学习报告」时：

1. **先看开班分校在不在白名单里**——不在名单里就是**合规屏蔽**，不是故障；
2. **再看学科 / 年级 / 授课类型**是否都在目标范围内；
3. **「报告入口是灰的」** → 报告**还没生成**，不是权限问题；
4. **别去客户端找原因**——客户端只有 H5 路由拦截，判断全在**服务端白名单**。

## 例外

- **白名单会变**（这份文档自己就改过 3 版），**以当前服务端配置为准**，不要拿上面的名单当永远正确；
- **老师从企微分享的报告不受这个限制**——所以「老师发给我的能看、APP 里没有」是正常的；
- 需求范围明确**含鸿蒙**（学而思 APP 的 iOS / Android / **鸿蒙**）。

**客户端代码核对结果**（仓库 `xesapp`，分支 `releaseV/20260921`，2026-09-23）：
「学习报告」**只在三端的 `XESRouterInterceptor.ets`（H5 路由表）里命中**；
「报告列表」「报告入口」「报告已生成」**零命中**——**报告是 H5 / 服务端渲染的**，
所以这条只能靠文档口径判断，**搜代码永远找不到**。
