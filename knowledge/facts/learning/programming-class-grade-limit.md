# 编程课堂的年级限制

## 事实

「编程课堂」入口在**学而思 HD → 我的**页面（**只在 HD，学而思 APP 上没有**），
版本要求 **V5.41.0 及以上**，分校不限。

**开放年级被收窄过**：

| | 展示年级 |
| --- | --- |
| 原规则 | **全部在读年级** |
| 现规则 | **仅大班、小学一年级、小学二年级** |

收窄的原因写在需求文档里：原规则下经常有**非投放年级**的用户来咨询、投诉「编程课堂无法使用」。

## 判据

用户说「编程课堂用不了 / 找不到」时：

1. **先看在读年级**——不在大班 / 小一 / 小二范围内就是**不展示**，设计如此；
2. 属于这三个年级仍看不到 → 检查 HD 版本是否低于 V5.41.0；
3. 用户说「学而思 APP 上找不到编程课堂」→ **它只在学而思 HD 的「我的」页面**。

## 例外

- 这是**入口展示规则**，不是功能可用性——如果入口在但点开打不开，那属于另一类问题；
- 客户端代码里搜「编程课堂」零命中，入口显隐由**服务端下发**控制，所以按名称搜代码找不到。

## 来源

《【20260825】学而思HD-编程课堂开放年级调整》知音楼 `https://s.tal.com/a/eRTeNL`（2026-07-24，刘东）——
**人工核实入口，agent 无访问能力**。

**客户端代码核对结果**（仓库 `xesapp`，分支 `releaseV/20260921`，2026-09-23）：
搜「编程课堂」**零命中**——该入口与显隐规则均由服务端配置控制，客户端不硬编码。
