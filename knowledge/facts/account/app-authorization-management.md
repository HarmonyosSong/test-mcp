# 应用授权管理（第三方数据打通）

## 事实

培优账号可以授权第三方应用访问自己的部分信息。当前唯一的授权应用是 **XNote**（智能笔记 + 录音笔
软硬件产品，**单向**从培优获取数据）。

- **入口**：我的 → 设置 → 账号与安全 → **应用授权**；
- **版本**：V7.104.0 及以上；
- **能看到**：已授权应用列表（图标、名称、最近一次授权时间，按授权时间**倒序**）；
  点进去是半屏详情弹窗，逐项列出该应用访问的信息范围；
- **可授权的数据范围**（服务端配置）：
  - 公开信息（昵称、头像）；
  - 在读年级、注册城市、性别；
  - 课程订单数据——**仅**上课中与未上课的班级名称、年份、日期、学科、课堂互动题目数据；
  - 课表与学情（含上课具体日期、业务线）；
- **取消授权**：点「取消授权」→ 成功 toast「已取消授权」，失败「取消失败，请稍后重试」；
  页面固定提示「取消授权后，如需再次使用此应用可能需要重新授权」。

**取消之后发生什么**（逆向流程，排查时最有用的一段）：

1. **停止继续数据同步**；
2. XNote 侧需**封存已同步的存量数据**（杜绝二次使用）——是**封存，不是删除**；
3. 再次使用需**重新授权**。

代码位置（鸿蒙侧）：

| 环节 | 文件 |
| --- | --- |
| 账号与安全页（应用授权入口） | `XesMine/src/main/ets/components/settings/pages/AccountSecurity.ets`（`type: 'appAuthorization'`） |

**应用名与授权文案都不在客户端**（搜「XNote」「取消授权」零命中）——由服务端配置下发，
所以新增授权应用不需要发版。

## 判据

用户问「谁拿走了我的数据 / 怎么断掉」时：

1. 指引到**我的 → 设置 → 账号与安全 → 应用授权**，那里能看到是哪个应用、何时授权；
2. 取消授权后同步停止，但**已同步的存量数据是封存而非删除**——对用户说"删了"不准确；
3. 取消后第三方应用可能**需要重新授权**才能继续使用；
4. 用户说「列表里看不到某个应用」→ 列表由服务端下发，且受版本限制（≥V7.104.0）。

## 例外

- 目前授权应用只有 XNote；数据同步范围变更须经**法务 + 产品**评估确认；
- 数据同步由数分团队负责，客户端只做授权展示与取消。
