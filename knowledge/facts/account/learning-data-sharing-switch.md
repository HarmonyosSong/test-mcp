# 学情数据共享开关

## 事实

集团在推进**跨事业部学情数据打通**（培优 / 网校 / 硬件 / 内容汇入「集团学情中台」），
家长侧的控制入口是权限设置里的 **`个性化推荐服务开关`**——需求文档里也叫「学情数据共享开关」，
**两个名字指的是同一个开关**。

- **位置**：我的 → 设置 → 权限设置；
- **版本**：≥ **V7.103.0** 才有这个开关；低于该版本页面没有开关，且**按关闭态处理**；
- **默认态**：**新版默认关闭**。代码注释原文：
  `新版个性化推荐服务默认关闭，接口缺少字段时按关闭态展示`
  （需求文档初版写过"默认开启"，v1.3 改成新增账号默认关闭——**以代码为准**）；
- **生效范围**：**1+5 模式**——一次操作对当前登录账号 + 用户中心已关联的全部账号生效；
  新绑定账号**默认未授权**，但后续任意一次开关变更会让关联账号**统一生效**；
- **审核态**：开关受 APP 审核开关影响，审核状态下隐藏，**仅对 iOS 与鸿蒙生效**；
- **关闭意味着**：撤回已共享的全部学情数据，且不再用于个性化服务；
  服务端由数仓定时扫描关闭名单执行撤回。

**鸿蒙侧的一个差异**：**协议更新提醒弹窗鸿蒙本期不支持**（Android & iOS 才有）。
其他端用户可以通过「同意协议」自动把开关置为开启，鸿蒙用户不会遇到这个弹窗。

代码位置（鸿蒙侧）：

| 环节 | 文件 |
| --- | --- |
| 权限设置页（本开关） | `XesMine/src/main/ets/components/settings/pages/PermissionSettingPage.ets` |

## 判据

用户问「我的 / 孩子的学情数据被共享到哪了」时：

1. 入口是**我的 → 设置 → 权限设置 → 个性化推荐服务开关**；
2. 用户说「我明明关过了还在共享」→ 检查版本是否 **< V7.103.0**（页面无开关，按关闭态）；
3. 用户说「另一个孩子的账号也在共享」→ 1+5 模式，**关联账号一起生效**；
4. 用户说「鸿蒙上怎么没弹协议提醒」→ **正常**，该弹窗鸿蒙本期不支持。

## 例外

- 开关有两个名字（学情数据共享开关 / 个性化推荐服务开关），**代码用后者**，
  按前一个名字搜客户端是零命中；
- 「页面没有开关」和「开关是关的」是两回事，对用户解释时要分清。
