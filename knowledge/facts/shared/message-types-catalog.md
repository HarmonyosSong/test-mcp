# 消息类型清单

## 事实

消息中心有**两层概念**：**消息类型**（20 种，消息列表里的分类）与**卡片类型**（49 种，具体模板）。

**消息类型**（20 种）：关注名额提醒、诊断提醒、报名成功提醒、付款提醒、支付成功提醒、课前须知、
上课提醒、考勤通知、加班群提醒、讲义提醒、退款通知、调课提醒、转班提醒、跨报提醒、学习报告、
评价提醒、系统通知、优惠券提醒、奖励通知、活动通知。

**卡片类型**（49 种，节选）：培优面授学习报告、IPS 作业提醒（催完成 / 点赞）、双师讲义提醒、
在线作业提醒（未作答 / 已批改 / 待查阅）、考勤通知、缴费成功通知、上课提醒、关注班级名额提醒、
报名成功提醒、入学诊断提醒、投诉反馈、班级群必达通知、课次报告、答题器报告、规划师报告、
小低评估报告、单门课 / 系列课报名成功通知、直播提醒、老带新领券提醒、诊断报告通知、
讲座退款通知、口述题（点赞 / 推荐 / 驳回）、云学习-勋章升级 / 领取红包 / 错题试卷导出、
作业批改、老师表扬学生等。

**清单里的废弃项**（排查时别把它们当成"应该有"）：

- `5 教师评价-已废弃` ← 当前使用的是 `36 教师评价-当前使用`
- `45 教师端点赞、提醒完成作业、督促学习-未使用`
- `47 云学习-老师督促学生-未使用`

## 判据

用户说「没收到 XX 提醒」时：

1. **先确认这个提醒是否存在** —— 对照上面的清单，别为不存在的类型排查；
2. **注意废弃 / 未使用项** —— 「教师评价」有两个卡片类型，旧的那个已废弃；若线上冒出旧的，
   那才可能是问题；
3. 「**我的**页面消息不显示」是另一条规则（30 天内无未读则整体隐藏），见 `my-page-entries`。

## 例外

- 清单来自 2025-11 的汇总文档，编号有跳号（如缺 18、42），**不保证覆盖全部**；
- 这是**类型清单，不是触发规则**——为什么某条消息没发，要看对应业务侧；
- **⚠️ 彼芯的 push 曾经被整体屏蔽过**：APP 早先屏蔽了**彼芯的各种消息通知**，
  后来彼芯回归 APP 时**只做了功能回归、push 没跟着回来**；
  2026-11 的订单需求才安排**恢复彼芯的 APP-push 与站内信**（对标素养，恢复**交易类**消息提醒）。
  而且**发不发 push 由上游交易侧控制**——所以「**彼芯收不到推送**」要先考虑这段历史，
  不一定是当前配置错了；
- **「关注名额」的触达渠道扩过**：原本**只有 APP 消息与公众号，短信只有彼芯有**；
  2026-06 起**班课（非彼芯）也加了关注名额短信**——线上模板 ID `11000000492`、
  测试 `11000000500`，模板名「关注名额-素养高中班课」，文案里会引导用户去
  「**我的 - 关注名额**」取消提醒或取消关注。
  所以「**彼芯有短信、别的业务线没有**」是**旧口径**。
