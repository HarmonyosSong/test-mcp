# App 搜索：词类分布与已知问题

## 事实

搜索是 C 端高频入口（日均约 1500 人使用）。**搜索词的类型分布**（估算占比；一个搜索词可能
同时命中多类，所以之和超过 100%）：

| 类型 | 关键词示例 | 占比 |
| --- | --- | --- |
| **授课老师** | 张老师、李xx | **35.2%** |
| **年级** | 一年级、初一、高三、大班 | 28.4% |
| **学科** | 数学、英语、语文、物理、编程 | 22.1% |
| **班次级别** | S班、A+、校优、勤思、创新 | 15.6% |
| **学期** | 春季、寒假、秋季、暑假 | 12.8% |
| 教学点 | 校区、大厦、中心、服务中心 | 4.5% |
| 上课形式 | 在线、网课、面授、线下 | 3.9% |
| 应用名称索引 | 诊断、测评、APP、下载 | 2.1% |
| 优惠活动 | 联报、立减、优惠 | 1.5% |
| 教材版本 | 北师、苏教、人教 | 0.8% |

**改造前已确认的问题**（"搜索结果不对"的已知原因）：

1. **缺乏语义理解**——纯拆词匹配。搜「高一数学」会给出大班数学，因为**只匹配了"数学"、忽略了年级**；
2. **模糊诉求理解不明确**——搜「**王老师**」搜不出来，搜「王XX」（带名字）可以；
3. **结果类型单一**——搜老师只出老师，不连带推荐该老师的课程。

改造方向：NLP 意图识别 + 实体拆分 → 策略组装 → 检索，意图分五类
（**找老师 / 找班级 / 找服务中心 / 找功能 / 其他无意图**）。

代码位置（鸿蒙侧）：

| 环节 | 文件 |
| --- | --- |
| 搜索页 | `XesCourseCenter/src/main/ets/search/NewSearchPage.ets` |
| 结果容器 VM | `XesCourseCenter/src/main/ets/search/viewModel/ResultContainerVModel.ets` |
| 搜索卡片组件 | `XesCourseCenter/src/main/ets/search/SearchMoreCardComponent.ets` |

**2026-03 起把传统搜索升级成了「AI 搜索」**（也叫智能搜索）——因为上面那些问题的根子就是
**只会拆词匹配**。链路是：**用户输入 query → NLP 模型（意图识别 ＋ 实体拆分）→ 策略组装 → 检索 → 前端展示**。

**五类意图**，每类对应一种卡片：

| 意图 | 典型 query | UI |
| --- | --- | --- |
| **找老师** | 搜「王老师」「初一数学名师」 | 教师卡片 |
| **找班级** | 搜「暑假数学」「S班」 | 班级卡片 |
| **找服务中心** | 搜「中关村教学点」「附近教学点」 | 服务中心卡片 |
| **找功能** | 搜「诊断」「客服」 | 功能卡片 |
| **其他（无意图）** | 搜「#QWE%^&」 | **AI 兜底话术** |

**「找服务中心」的召回与排序**（二期）：模型识别 query 里的**教学点 / 行政区**实体；
召回做**强过滤**（教学点名 / 行政区名 ＋ 城市——query 没带城市时取**学员城市**，未登录则不限城市）；
排序先看**名称匹配度**（全匹配 `+50`、部分匹配 `+30`），再看**距离**（已授权定位时按由近及远）。

**交互上的几个硬数字**（对排查很有用）：

- 输入**最多 60 个字**，**语音识别也限 60 字**；
- **灰度**：支持**按城市配置**逐步放量；
- **入口方式**：本期用的是「**原搜索框下方加一个「AI 搜索」开关按钮**」
  （打开走 AI、关闭走原关键词搜索），**不是**搜索页分两个 tab；
- **历史记录**：保留，默认展示**两行**、超出可展开；**单个词条最多 10 个字**，支持单个 / 全部删除；
- **搜索建议「试试这样问」**：展示 3~5 条，**只有 AI 搜索打开时才出现**（关闭不展示）；
- 搜索结果里**命中的 query 词会高亮**。

## 判据

用户说「搜索搜不到 / 结果不对」时：

1. **先看搜的是什么类型**——「王老师」这类**不带名字的老师搜索**是**改造前**的已知问题
   （当时只能搜「王XX」才出结果）；**2026-03 起的 AI 搜索，其「找老师」意图的典型 query 就是「王老师」**——
   所以先确认**用户开没开 AI 搜索、版本够不够**，再判断是不是问题；
2. **年级被忽略**——「高一数学」出「大班数学」属于拆词匹配的已知行为；
3. 一个词可能同时属于多类（"初一数学春季" = 年级 + 学科 + 学期），结果多不一定是错。

## 例外

- 搜索的**召回与排序在服务端**，客户端只渲染——别在客户端找匹配逻辑；
- 上述问题是**改造前**的记录，改造上线后行为可能已变，以当前版本为准。
