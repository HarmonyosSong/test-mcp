# 资源位 / 弹窗的班级过期机制

## 事实

首页的**广告弹窗、资源位**可以按**班级 / 课程 ID** 投放。配置的班级过期时该资源位会被**下架**
——这是「弹窗突然不显示了」的常见原因。

**「过期班级」的四种判定**（任一命中即算过期）：

1. 班级对应课程**售卖状态下架**；
2. 班级所属**产品上架状态下架**；
3. 班级所属产品**没绑定招简**；
4. 班级**售卖状态下架**。

**校验时机**：

- **上传时**：校验表格里是否有已过期班级 ID，有则**不允许保存配置**（三种状态：校验中 / 校验成功 /
  校验失败，失败时提示「班级ID XXX 已过期，请重新上传」）；
- **投放期内**：**每间隔 1 小时**检测一次，**只要有一个班级过期就下架该资源位**；
- **例外**：班级对应课程的售卖渠道是**内部售卖**时，**不做** ID 过期校验。

## 判据

用户说「首页弹窗 / 活动不显示了」时：

1. **先查该资源位绑定的班级有没有过期**——按上面四条判定；
2. 注意是**该资源位单独下架**，不是整个位置都没了——历史上一个班的过期会拖垮该位置
   **所有**资源位，这个缺陷后来才修成"逐个下架"；
3. **内部售卖渠道**的班级不受此校验影响。

## 例外

- 资源位与弹窗由**服务端配置下发**，客户端搜「资源位」零命中（已核对）；
- 具体投放状态要在灯塔后台查，agent 查不到。
